Create Table Parser

结构化解析建表 SQL

从 CREATE TABLE 语句中提取表名、字段定义、键、分区、分桶和表属性，便于 DDL 审核、元数据采集及数据库迁移。

DDL 解析示例
CREATE TABLE orders (
  id BIGINT NOT NULL,
  amount DECIMAL(18,2),
  created_at DATETIME
) PRIMARY KEY(id);

字段：3 · 主键：id

从 DDL 到结构化元数据

一次解析获取建表语句中的关键结构。

字段定义

提取字段名、数据类型、可空性、默认值和注释。

键与索引

识别主键、唯一键及数据库方言特有的键模型。

分区与属性

解析分区、分桶和 properties 等扩展配置。

适用范围

适合用于 DDL 审核、元数据录入、数据库迁移评估、建表规范检查和开发测试。不同数据库的扩展语法存在差异，使用时应选择与 SQL 对应的方言。

工具会在数据库中创建表吗？

不会。工具仅解析 SQL 文本并展示结构化结果。
