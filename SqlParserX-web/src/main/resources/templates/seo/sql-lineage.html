SQL Lineage

在线解析 SQL 表级与字段级血缘

从复杂 SQL 中追溯来源表、目标表及字段映射，辅助影响分析、数据治理和任务排障。支持 CTE、JOIN、子查询、UNION、INSERT 与 CTAS 等常见结构。

立即体验血缘解析阅读使用文档
MySQL · 血缘示例
INSERT INTO order_summary
SELECT u.id, SUM(o.amount)
FROM users u JOIN orders o
  ON u.id = o.user_id;

users.id ─────→ order_summary.id
orders.amount ─→ order_summary.total

一条 SQL，两种血缘视角

从整体依赖到字段映射逐层定位数据来源。

表级血缘

识别来源表、目标表及中间查询关系，快速建立任务依赖图。

字段级血缘

分析表达式、聚合函数与 CASE 中的字段依赖和目标字段映射。

多方言支持

覆盖 MySQL、Hive、Doris、Oracle、PostgreSQL、Spark 等数据库方言。

适用场景

SQL 血缘可用于数据资产治理、变更影响分析、指标口径追踪、数据质量排查以及调度任务依赖梳理。SqlParserX 基于语法树理解 SQL 结构，不依赖简单的文本匹配。

是否需要上传数据库数据？

不需要。工具解析的是输入的 SQL 文本；请勿输入敏感业务数据。

可以解析复杂查询吗？

支持常见的 CTE、JOIN、UNION、子查询、INSERT 和 CTAS 结构，具体结果与所选方言及 SQL 合法性有关。
