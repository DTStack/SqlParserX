SQL Splitter

安全切分多语句 SQL 脚本

识别分号、字符串和注释上下文，将批量 SQL 脚本拆分为独立语句，便于逐条解析、审计、执行或迁移。

多语句切分示例
SELECT 'a;b' AS value;
-- comment with ;
UPDATE users SET active = 1;

结果：2 条有效 SQL 语句

理解上下文的语句切分

不仅按分号截断，还要正确处理字符串和注释。

语句边界识别

定位脚本中的有效结束符并保持语句完整。

字符串保护

避免误切字符串字面量内部的分号。

策略对比

支持自定义与原生切分方式的结果测试。

常见用途

SQL 切分适用于批量脚本导入、逐句语法检查、SQL 审计、迁移工具和开发调试。切分只确定语句边界，不代表每条 SQL 均可在目标数据库成功执行。

字符串中的分号会被拆开吗？

切分器会结合字符串与注释上下文识别边界，避免把普通文本中的分号直接当作结束符。
