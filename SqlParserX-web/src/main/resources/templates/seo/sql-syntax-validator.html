使用建议

语法校验用于确认 SQL 能否被指定方言的解析器正确识别，不等同于连接数据库执行，也不会验证表和字段是否真实存在。生产执行前仍应结合数据库权限、元数据和执行计划检查。

会执行输入的 SQL 吗？

不会。该工具只进行语法解析，不连接业务数据库执行语句。
