穿透别名、CTE 和嵌套查询，识别查询涉及的主表与全部真实物理表，为审计、权限分析和血缘建设提供结构化结果。

立即解析表名了解 SQL 血缘
CTE 表提取示例
WITH paid AS (
  SELECT * FROM orders
)
SELECT p.id, u.name
FROM paid p JOIN users u
  ON p.user_id = u.id;

真实表：orders, users

常见用途

表名解析适用于 SQL 权限预检、查询审计、任务依赖采集、数据源迁移和静态代码分析。解析结果来自 SQL 语法结构，不访问数据库元数据。

CTE 名称会作为真实表返回吗？

工具会分析 CTE 定义并尽可能返回其内部引用的真实表，而不是仅返回临时名称。
