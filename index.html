核心能力

一个引擎，覆盖 SQL 解析全链路

从方言语法到业务语义，统一契约、统一结果，开箱即用。

SQL 类型识别

识别查询、写入、建表、SHOW 与 EXPLAIN 等语句类型。

真实表与建表结构

穿透 JOIN、CTE 与子查询，解析字段、键、分区及分桶结构。

表级血缘

从 INSERT 与 CTAS 追溯来源表到目标表的数据流转关系。

字段级血缘

分析表达式、函数与 CASE 中来源字段到目标字段的映射。

函数名提取

提取普通、聚合与窗口函数名称，支持多语句解析与去重。

参数提取与预编译

提取 SELECT 动态参数，生成 JDBC 占位符 SQL 与有序绑定值。

架构设计

两层统一扩展架构

语法层基于 Druid 扩展方言 Lexer / Parser / AST，业务层通过 ISqlParser 契约扩展表解析、血缘与改写逻辑，两层由 DbType 与 AST 对齐。

  2. 2语法层解析为 Druid AST
  3. 3业务层统一解析
  4. 4表 / 血缘 / 函数 / 参数解析结果
